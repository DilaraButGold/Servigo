# Servigo – School Shuttle Management System

Digital platform for school shuttle operators: live tracking, QR attendance, automated payments, route optimization.

## Development Phases
- **Phase 0**: Monorepo setup
- **Phase 1**: Auth + Roles (JWT)
- **Phase 2**: CRUD for Students/Parents/Drivers/Teachers
- **Phase 3**: Real‑time absence notifications (Socket.io)
- **Phase 4**: Live location & ETA (Android + Web)
- **Phase 5**: KM‑based pricing + monthly payments (iyzico)
- **Phase 6**: QR/NFC check‑in/out
- **Phase 7**: Route optimization (Mapbox/OSRM)
- **Phase 8**: Emergency button + capacity control
- **Phase 9**: Driver performance reports + chat
- **Phase 10**: Testing, PWA, documentation

## Tech Stack
- **Backend**: Node.js + Express + TypeScript + Prisma + PostgreSQL
- **Web**: React + Vite + Tailwind + shadcn/ui
- **Mobile**: React Native (Expo) + TypeScript
- **Realtime**: Socket.io
- **Payments**: iyzico
- **Maps**: Mapbox / Google Maps
